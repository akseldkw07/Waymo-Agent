## Action Heuristic

This module provides heuristics for determining actions in the Waymo Agent environment.

The idea is to implement simple, rule-based strategies that can be used as baselines or for testing purposes. These heuristics can help in scenarios where a full reinforcement learning policy may not be necessary or feasible.

### Available Heuristics
The actions exposed in this module have a 1:1 mapping to the actions defined in `graph_env/mixin/action_mixin.py`.
